# Discord Music Bot with Spotify Integration

A feature-rich Discord music bot that can play music from YouTube, Spotify, and parse music library content.

## Features
- 🎵 Play music from YouTube
- 🎧 Spotify integration (search and metadata)
- 📊 Parse and play from music library content
- 🔄 Queue system with loop mode
- 🎚️ Volume control
- 📱 Interactive embeds and reactions
- 🔐 Environment-based configuration

## Prerequisites
- Python 3.8+
- FFmpeg installed on your system
- Discord Bot Token
- Spotify Developer Account (optional)

## Installation

1. **Clone or download the project**
2. **Install FFmpeg:**
   - **Windows:** Download from [ffmpeg.org](https://ffmpeg.org/download.html)
   - **Linux:** `sudo apt install ffmpeg`
   - **Mac:** `brew install ffmpeg`
